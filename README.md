#  Missing People Project

A web-based platform designed to help track and share information about missing individuals. This project leverages technology to support families, communities, and authorities in locating missing persons more effectively.

---

##  Reason for This Project

Thousands of people go missing every year, and many cases lack the visibility and tools needed to solve them. The **Missing People Project** was created to:

- Provide a centralized system for reporting and tracking missing individuals.
- Help spread awareness by making information easily accessible and shareable.
- Support faster and more efficient searches through digital tools.
- Empower communities and law enforcement with better data and communication.

---

##  Technologies Used

This project is built using:

- **MongoDB** – A NoSQL database used to store user-submitted reports and case data.
- **JavaScript** – For the backend logic and interactive frontend features.
- **React.js** – A powerful frontend library used to build a dynamic and responsive user interface.

---

## Features

- Add new missing person reports with photo and last known location.
- Search and browse through active cases.
- View detailed case pages with contact info and descriptions.
- (Optional) Admin panel for managing and verifying cases.
